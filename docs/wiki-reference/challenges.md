# Megabonk Wiki Reference — Challenges

Source: https://megabonk.wiki/wiki/Challenges (community wiki, MediaWiki)
Snapshot date: 2026-08-17

This is a point-in-time snapshot of community-maintained wiki content. It is **not official game documentation** and may drift from actual current game behavior/balance as patches are released. Use as a reference/hint source only — verify against live event data where possible.

## Overview

Only one Challenge can be active per run. Challenge runs do not upload to leaderboards. Completing a Challenge grants a permanent +1% Silver gain increase (cumulative across all completed Challenges). Goal for nearly all listed Challenges is "Kill all bosses" (i.e., clear the tier) unless otherwise noted.

## Notes

The wiki page did not list any Graveyard-specific Challenges as of this snapshot — Challenges appear to currently be Forest and Desert only. The "oh no"/"oh shit"/"what the fuck" tier progressively raises enemy HP/Damage/Speed multipliers together; these appear at every tier of both maps with the reward scaling from 1.5x to 2x as the multiplier increases.
